# TCK-026: Passive Start BDD, Clean Splitter & Unified Input Bar

## 🎯 Intention & UX-Sanering
- Åtgärda tystnaden vid start genom att kräva explicit User Gesture (klick på Live-knapp) för mikrofon och WebSocket.
- Smalna av mittdelaren till en ultra-tunn linje (< 4px) utan mekaniska pilknappar.
- Ersätta den 4-knappars reflektionslisten med en kompakt Dropdown ([ Reflektion: Normal ∨ ]) i prompt-baren.
- Separera STT-diktering (Mikrofon-ikon) från realtids Live-Agent (Live-ikon/Starta Live).

## 📐 Kravspecifikation & Ingrepp

1. BDD Feature & Step Definitions:
   - Skapa doc/features/unified_chat_input.feature och src/__tests__/bdd/unified_chat_input.test.ts FÖRST.
   - Verifiera att ingen WebSocket startar förrän användaren klickar på Live-knappen.

2. Canvas & Delare (src/features/gemini_live_swarm/ui/SplitPaneCanvas.tsx):
   - Minska splitter-bredden till 3px.
   - Radera alla pil-knappar på delaren (behåll endast drag-events).

3. Enhetlig Prompt-Bar (src/features/gemini_live_swarm/ui/AppShell.tsx):
   - Integrera dropdown för Reflektionsläge (Normal, Mikro, Makro, Meta).
   - Lägg till Mikrofon-knapp för Speech-to-Text (diktering till textarea).
   - Lägg till Live-knapp (Starta/Pausa Live-session) som anropar `geminiLiveSession.start()` / `stop()`.

4. Session & Web-APIs (src/features/gemini_live_swarm/session/geminiLiveSession.ts):
   - Säkerställ att `navigator.mediaDevices.getUserMedia()` och `AudioContext.resume()` exekveras strikt i klick-handlern för Live-knappen.
