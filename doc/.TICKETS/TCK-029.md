# TCK-029: UI Telemetry & Cirkulär Diagnostikbuffert i WAL

## 🎯 Intention
Koppla en rullande RAM-buffert till `walLogger` som lagrar de 5 senaste UI-interaktionerna (3 sekunders PCM-ljud + skärmdump) för snabb och exakt feldiagnostik utan tung videoströmning.

## 📐 Kravspecifikation & Ingrepp

1. Telemetri-lyssnare (`src/features/wal_logger/walUiTelemetry.ts`):
   - Prenumerera på de specifika event som TCK-027 och TCK-028 sänder på `SwarmEventBus`: `UI_STATE_CHANGED`, `MUTEX_TOGGLED`, `SESSION_CONFIG_UPDATED`, `swarm.session.text_delta` och pendeltillstånd.

2. Cirkulär Ringbuffert (`src/features/wal_logger/engine/transientRingBuffer.ts`):
   - Håll max 5 poster i minnet (~176 KB/post, < 1 MB totalt RAM).
   - Vid interaktion #6 skrivs den äldsta posten över automatiskt.
   - **Buffer Flush:** Vid klick på `[ ↩ Restore ]` i UI:t ska denna RAM-buffert tömmas helt så att gammal historik inte finns kvar efter tillståndsåterställning.

3. Crash Dump Artefakt (`doc/LAST_CYCLE/`):
   - Vid ohanterat fel eller buggrapport fryses bufferten och skrivs till disk tillsammans med WAL-loggen.

## 🧪 Verifiering

`pnpm verify` ska köra isolerade enhetstester:
- **Test 1:** Verifiera att rullande bufferten aldrig överstiger 5 element i RAM.
- **Test 2:** Verifiera att `[ ↩ Restore ]` utför flush på transientRingBuffer.
- **Test 3:** Verifiera att `SESSION_CONFIG_UPDATED` (reflektionsval) loggas korrekt i telemetrikedjan.
