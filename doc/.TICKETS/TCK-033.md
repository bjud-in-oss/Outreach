# Biljett: TCK-033 - Minnesindikator i promptfältet

## Beskrivning:
Implementera en minnesindikator i `UnifiedPromptBar` som visar återstående token-kapacitet som en procentsats [Ledigt X%]. Detta görs genom att utnyttja `ContextUsageMetric` från `useSwarmTelemetry` och tillgängliggöra den via svärmens kontext.

## FSD-Avgränsning:
Domän: `features/gemini_live_swarm/`
Källkodsfiler som påverkas:
- `ui/UnifiedPromptBar.tsx` (Vyn för promptfältet)
- `context/SwarmContext.tsx` (Exponering av telemetridata)

## Tekniskt Kontrakt (FSD & Zod):
Indikatorn ska läsa `usageRatio` och beräkna ledigt minne som `Math.round((1 - usageRatio) * 100)`.

```typescript
export interface MemoryIndicatorProps {
  usageRatio: number;
}

export function formatMemoryIndicator(usageRatio: number): string {
  const freePercentage = Math.round((1 - usageRatio) * 100);
  return `[Ledigt ${freePercentage}%]`;
}
```
