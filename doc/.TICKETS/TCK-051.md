# TCK-051: Skarp Mikrofonströmning, Live-transkribering och Agentstyrd A2UI-brygga

**Måldomän:** `gemini_live_swarm` (`src/features/gemini_live_swarm/`)
**Målfiler:** `src/features/gemini_live_swarm/session/liveBridgeHelper.ts`, `src/features/gemini_live_swarm/session/geminiLiveSession.ts`
**Mekanisk Acceptans:** Ett transient test bevisar (Fail-First mot körtidsankare utan `vi.fn()`-spioner) att:
1. PCM-ljud som emitteras på `SwarmEventBus` (`'swarm.live.stream.audio'`) vidarebefordras till den aktiva WebSocket-sessionens `sendRealtimeInput` med formatet `{ audio: { data, mimeType } }`.
2. När `SessionIntentManager.activateIntent('CONSULT')` eller händelsen `'swarm.live.intent.activated'` körs publiceras `'a2ui:render'` med `{ componentId: 'ListeningCard', dataModel: { intent: 'Att förlikas' } }`, och vid `'swarm.live.intent.deactivated'` publiceras `'a2ui:clear'`.
3. Verktygsanrop (`toolCall.functionCalls`) för `render_a2ui` och `clear_a2ui` i `handleAgentMessage` vidarebefordras till `SwarmEventBus` och besvaras via `sendToolResponse`.
Samtliga tester, AST-kontroller (Gate 2c), radgränser (<250 rader i `.ts`) och FSD-arkitekturkontroller passerar med exit 0.

## Misstagsäkring & Systemiska Invarianter (Stoppklossar)
1. **Komplett implementation i båda målfilerna:**
   - Skriv `src/features/gemini_live_swarm/session/liveBridgeHelper.ts` via `save_code` med all brygg- och meddelandehantering nedan.
   - Uppdatera `src/features/gemini_live_swarm/session/geminiLiveSession.ts` via `apply_patch` så att den delegerar till `liveBridgeHelper.ts` och håller sig under 240 rader.
   - **Obligatorisk Gate 2c-städning i `geminiLiveSession.ts`:** Ersätt de två befintliga tomma `catch {}`-blocken ordagrant:
     * `if (this.activeSdkSession?.close) { try { this.activeSdkSession.close(); } catch {} }` -> `if (this.activeSdkSession?.close) { try { this.activeSdkSession.close(); } catch (err) { console.warn('[GeminiLiveSession] close', err); } }`
     * `private notifyListeners(chunk: LiveStreamChunk): void { for (const listener of this.streamListeners) { try { listener(chunk); } catch {} } }` -> `private notifyListeners(chunk: LiveStreamChunk): void { for (const listener of this.streamListeners) { try { listener(chunk); } catch (err) { console.warn('[GeminiLiveSession] listener', err); } } }`
2. **Modulär brygga i `src/features/gemini_live_swarm/session/liveBridgeHelper.ts` (< 130 rader):**
   - Exportera `A2UI_TOOL_DECLARATIONS` (`render_a2ui` och `clear_a2ui`).
   - Exportera `packBidiAudioChunk(data: string, mimeType = 'audio/pcm;rate=16000')` som returnerar `{ audio: { data, mimeType } }`.
   - Exportera `bindLiveSwarmBridge(bus: SwarmEventBus, getSession: () => any, isConnected: () => boolean, onDisconnect: () => void)` som prenumererar på:
     * `'swarm.live.stream.audio'`: läser `audioChunkBase64` eller `data` och anropar `session.sendRealtimeInput(packBidiAudioChunk(...))` när `isConnected()` är sant.
     * `'swarm.live.intent.activated'`: emitterar `bus.emit('a2ui:render', { componentId: 'ListeningCard', dataModel: { intent: payload?.title || 'Lyssnar aktivt' } })`.
     * `'swarm.live.intent.deactivated'`: emitterar `bus.emit('a2ui:clear', {})`.
   - Exportera `handleLiveToolCalls(functionCalls: any[], bus: SwarmEventBus, sendToolResponse: (responses: any[]) => void)` som hanterar `render_a2ui` och `clear_a2ui` och skickar `{ id, name, response: { ok: true } }`.
   - Exportera `processLiveServerTranscripts(message: any, bus: SwarmEventBus)` som emitterar `message?.serverContent?.outputTranscription?.text` och `inputTranscription?.text` som `'swarm.session.text_delta'`.
3. **Uppdatering av `src/features/gemini_live_swarm/session/geminiLiveSession.ts` (< 250 rader):**
   - Delegerar `packRealtimeAudioChunk` och `subscribeToMicPiping` till `packBidiAudioChunk` och `bindLiveSwarmBridge`.
   - I `connectLive`: inkludera `inputAudioTranscription: {}`, `outputAudioTranscription: {}` och `tools: [{ functionDeclarations: A2UI_TOOL_DECLARATIONS }]` i `makeAgentConfig`.
   - I `handleAgentMessage`: anropa `processLiveServerTranscripts(message, this.eventBus)` samt `handleLiveToolCalls(message.toolCall.functionCalls, this.eventBus, (r) => this.sendToolResponse(r))` när `message?.toolCall?.functionCalls` finns.
   - Exponera `public attachSdkSession(sdkSession: any): void` som sätter `this.activeSdkSession = sdkSession; this.liveStatus = 'STREAMING';`.
4. **Exakta signaturer i tester och FSD-isolering:**
   - Instansiera sessionen med `new GeminiLiveSession('test-api-key', eventBus)` och använd `intentManager.activateIntent('CONSULT')`.
   - Inga importer från `src/features/a2ui/` och använd standard Vitest-assertions (`toBeDefined()`, `toEqual()`).

## Scenariotriad (Den relationella och systemiska avsikten)

**Scenario: ATT FÖLJA – Rösten bär fram till agenten och väcker det generativa gränssnittet**
  Givet att användaren aktiverar mikrofonen i chattfältet
  När PCM-ljudströmmen och intent-händelser sänds över `SwarmEventBus`
  Så ska ljudpaketen nå Gemini Live WebSocket utan att tappas bort, `ListeningCard` tändas automatiskt och agenten kunna styra A2UI-kort via `render_a2ui`
  Och användaren upplever ett levande, multimodalt samtal.

**Scenario: ATT VÄNDA OM – Avvisande av felaktiga ljudkuvert och tysta catch-block**
  Givet att Gemini Live SDK kräver `{ audio: { data, mimeType } }` och Gate 2c förbjuder tomma `catch {}`
  När `GeminiLiveSession` delegerar till `liveBridgeHelper.ts` och hanterar undantag
  Så är varje felkanal dokumenterad och källkoden slank under 250 rader
  Så att bygget och strömningen fungerar utan avbrott.

**Scenario: ATT FÖRLIKAS – En ren och modulär brygga**
  Givet att källkod och tester är skapade under `src/features/gemini_live_swarm/`
  När `pnpm verify` körs
  Så ska samtliga domäntester och FSD-arkitekturkontroller passera med exit 0.
